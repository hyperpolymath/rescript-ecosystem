This repository is a **donation-staging wrapper** for six ReScript-related
libraries and tools built by
https://github.com/hyperpolymath[Hyperpolymath]. The work is offered to the
ReScript community for long-term stewardship.

== What is here

Seven independent repositories are collected under this wrapper:

* **rescript** — hyperpolymath fork of the upstream ReScript compiler
* **rescript-tea** — The Elm Architecture for ReScript (v12+, ES modules, zero deps)
* **rescript-evangeliser** — JS→ReScript pattern-detection and teaching toolkit
* **rescript-string-power** — Tagged template utilities (SQL, CSS, GraphQL, i18n)
* **rescript-vite** — Zero-config ReScript + Vite with examples, templates, tutorial, and scaffolder (production-ready)
* **bridge-web-rescript** — TypeScript-free PWA framework (specification stage)
* **rescript-wasm-runtime** — Deno + WASM runtime bindings for ReScript

Each child is its own git repository with its own GitHub remote under
`github.com/hyperpolymath/`. This wrapper holds only documentation and a
machine-readable manifest; the children are referenced by URL, not embedded.
